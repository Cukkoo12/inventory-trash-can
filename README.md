# Inventory Trash Can

A mod that allows for the quick and practical disposal of unnecessary items directly from the Minecraft inventory.

## Features

* Integrated trash can mechanism within the inventory interface.
* Support for quick deletion of unwanted items.

## Technical Requirements

* **Minecraft Version:** 26.1
* **Mod Loader:** Fabric (>=0.18.5)
* **Java Version:** Java 25

## Installation

1. Install the Fabric mod loader for Minecraft 26.1.
2. Download the `inventory-trash-can-1.0.0.jar` file from the repository's "Releases" tab.
3. Place the downloaded `.jar` file into your Minecraft `mods` folder.
4. Launch the game.
